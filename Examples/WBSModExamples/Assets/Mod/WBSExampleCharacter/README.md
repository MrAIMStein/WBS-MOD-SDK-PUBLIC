# 人物模型示例

这个示例演示“源模型 → 制作配方 → 完整人物 → 模组成品”。人物登记入口由打包工具自动生成，制作这类模组不需要编写 C#。

## 从哪里开始

按 [示例工程说明](../../../README.md) 打开工程后，查看以下文件：

| 文件或目录 | 用途 |
| --- | --- |
| `AuthoringSource/m3_Source.prefab` | 制作时使用的源模型 |
| `AuthoringSource/OriginalM3/` | 源模型引用的网格、Avatar、材质和贴图 |
| `Editor/Recipe.asset` | 人物名称、模型、材质、视角和来源许可等制作配置 |
| `Art/Prefabs/Character_Multi/m3.prefab` | 制作工具生成的完整游戏人物 |
| `Editor/Build.asset` | 本示例的模组信息、人物配方和打包配置 |

打开 `WBS/角色/角色制作工具`，选择 `Editor/Recipe.asset`，查看源模型和材质配置。需要重新制作时先检查配置，再点击“生成完整人物”。打开 `WBS/模组/打包工具`，选择 `Editor/Build.asset`，点击“检查”，通过后点击“打包发布目录”。

详细制作、打包与调试步骤见 [制作与打包指南](../../../../../Documentation/使用说明.md)。

## 换成自己的模型

1. 通过 `WBS/模组/新建模组` 创建自己的模型模组，取得独立的 UUID、KeyName 和制作配方。不要沿用本示例的身份发布另一个模组。
2. 将自己的模型与资源放入新模组目录，确认具有有效的 Humanoid Avatar。VRM 模型先按 [导入指南](../../../../../Documentation/VRM模型导入.md) 准备。
3. 在新配方中设置源模型、人物名称、材质和来源许可，参考本示例配置视角与布娃娃。
4. 生成完整人物，在游戏中检查选择预览、正式角色、头像、遗体和材质表现，再打包发布。

后续升级自己的模组时，保留原配方、模组身份、人物 ID 和资源 `.meta`。需要采用新 SDK 人物模板时使用“刷新到当前模板”，并处理工具报告的手工修改差异；具体见 [游戏更新与模组升级](../../../../../Documentation/升级与游戏更新.md)。
